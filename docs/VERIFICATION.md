# ผลตรวจสอบเวอร์ชันส่งมอบ

## เพิ่มโค้ด Java อธิบายข้างเกม — 3 พฤศจิกายน 2569 (Asia/Bangkok)

- เพิ่มตัวอย่าง Bubble Sort, Stack และ Queue พร้อม syntax highlighting เลขบรรทัด ค่าตัวแปร และคำอธิบายไทยที่เปลี่ยนตามขั้นตอน
- `node --test test/visualizer_test.js` ผ่าน 19 กรณี รวมการส่งสถานะให้แผงโค้ด การไฮไลต์ตาม compare/swap/keep/push/pop/enqueue/dequeue การเล่นซ้ำ และการข้ามภาพ
- คอมไพล์โค้ด Java ทั้งสามตัวอย่างจากข้อความที่แสดงจริงด้วย `javac --release 21` และรันทดสอบ Bubble Sort กับค่าซ้ำ, LIFO/FIFO และการป้องกันนำออกจากรายการว่าง ผ่านทั้งหมด
- `node --check web/app.js` และ `node --check web/visualizer.js` ผ่าน
- ตรวจ Chrome จริงด้วยฐานข้อมูลทดสอบ: Stack แสดงแผงโค้ดข้างกระดาน การ PUSH ไฮไลต์บรรทัด 3–4 ก่อนตอบไฮไลต์บรรทัด 7–8 และเมื่อเลือก 12 จะไฮไลต์ POP บรรทัด 11–12 พร้อม top = 1
- เปลี่ยนเฉพาะส่วนแสดงผลและการส่งสถานะภาพในเบราว์เซอร์ รอบนี้ไม่ได้รัน Java/API suite ใหม่ ผลรอบก่อนอยู่ด้านล่าง

## เพิ่มแอนิเมชันระหว่างเล่น — 3 พฤศจิกายน 2569 (Asia/Bangkok)

- `sh test.sh` ผ่าน: Java 698 assertions และ API 804 assertions ครบทั้ง 15 ด่าน ด้วยฐานข้อมูลและพอร์ตชั่วคราว
- ตรวจสถานะก่อน PUSH/ENQUEUE และหลังการสลับ/POP/DEQUEUE ทั้งคำตอบถูก คำตอบผิด และขั้นตอนสุดท้าย โดยไม่เปิดสถานะเฉลยก่อนส่งคำตอบ
- `node --test test/visualizer_test.js` ผ่าน 13 กรณี ครอบคลุมค่าซ้ำ ลำดับข้อมูล การเล่นซ้ำโดยไม่แก้ข้อมูล การข้าม/ยกเลิกภาพ ความเร็ว reduced motion และการออกแล้วกลับหน้าเกมขณะรอคำตอบ
- `node --check web/app.js` และ `node --check web/visualizer.js` ผ่าน
- ตรวจ Chrome จริงด้วยบัญชีและฐานข้อมูลชั่วคราว: หน้า Bubble Sort แสดงแท่งตัวเลขคู่ที่เปรียบเทียบได้ ตอบผิดแล้วแสดงลำดับ 3, 8, 5, 1 ตามเฉลย ปิดปุ่มคำตอบทั้งคู่ และเปิดปุ่มไปขั้นตอนถัดไป
- การควบคุมเบราว์เซอร์ขาดช่วง จึงยังไม่ได้ตรวจแอนิเมชัน Stack/Queue และทุกขนาดจอด้วยตาจริง การทำงานส่วนนี้ตรวจด้วย Java/API และ Node tests ตามข้างต้น
- เซิร์ฟเวอร์ที่เปิดจากโค้ดรุ่นเดิมต้องหยุดแล้วรันใหม่ เพื่อโหลด API และ static asset `visualizer.js` รุ่นใหม่

## เวอร์ชันก่อนเพิ่มแอนิเมชัน

วันที่ 2 พฤศจิกายน 2569 (Asia/Bangkok)

- คอมไพล์ Java ด้วย --release 21 บน OpenJDK 25 สำเร็จ
- Java assertions 301 รายการผ่าน
- API assertions 520 รายการผ่าน
- เล่นจบทั้ง 15 ด่านผ่าน API ตรวจผลคะแนนและคำตอบทุกขั้นตอน
- ตรวจการส่งคำตอบขั้นตอนเดิมพร้อมกัน: รับเพียงหนึ่งครั้ง
- ตรวจว่าผู้ใช้คนอื่นอ่านประวัติ/คำตอบของเจ้าของไม่ได้
- ตรวจว่าผลลัพธ์และเกมค้างยังอยู่หลังหยุดและเปิดเซิร์ฟเวอร์ใหม่
- ตรวจว่าตารางอันดับเลือกผลดีที่สุดคนละหนึ่งรายการต่อด่าน
- ตรวจคำสั่งเริ่มเกมข้าม Origin ถูกปฏิเสธ และโค้ดภายในไม่ถูกเสิร์ฟผ่านเว็บ
- ตรวจ JavaScript syntax ด้วย node --check สำเร็จ
- ทดสอบในเบราว์เซอร์จริง: สมัครสมาชิก เลือกด่าน Bubble Sort ตอบผิด/ถูก ดูเฉลย รีเฟรชแล้วได้ขั้นตอนถัดไป และกลับหน้าแรกเพื่อเล่นต่อ
- ตรวจหน้าตาจริงในพื้นที่แสดงผลกว้างประมาณ 689 px; ยังไม่ได้ตรวจทุกขนาดหน้าจอหรือเครื่อง Windows จริง
- ตรวจ SHA-256 ของ H2 JAR ตรงกับ Maven Central

ชุดทดสอบใช้ฐานข้อมูลและพอร์ตชั่วคราว ส่วน ZIP ไม่รวมฐานข้อมูลบัญชีทดสอบหรือไฟล์ build เมื่อนำไปใช้จะเริ่มฐานข้อมูลว่างและสร้างตาราง/ข้อมูลด่านอัตโนมัติ

เวอร์ชันนี้เป็นเว็บรันบนเครื่อง ยังไม่ได้เผยแพร่ผ่านอินเทอร์เน็ต และแนบโครงร่างสำหรับรายงาน ยังไม่มีรายงาน PDF/DOCX ฉบับส่ง
